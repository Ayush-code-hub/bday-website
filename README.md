# Happy Birthday Sweety

Animated birthday website.

## Files
- `index.html` - the whole website (design, animations, wishes)
- `photo.jpg` - the photo hidden behind the curtain
- `app.py` - Streamlit wrapper that shows the website full screen
- `requirements.txt` - Streamlit dependency

## Run on your computer
```
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud
1. Push all four files to a GitHub repository (keep them in the same folder).
2. Go to share.streamlit.io, choose "Create app", pick the repository and set the main file to `app.py`.
3. Deploy, then share the app link.
